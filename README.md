# winterridgeventures.com

Static site for Winter Ridge Ventures LLC, hosted free on GitHub Pages.

- `index.html`: the whole site (About, Projects, Contact)
- `style.css`: styles (light and dark)
- `favicon.svg`: logo mark
- `404.html`: not-found page
- `CNAME`: custom domain for GitHub Pages

No build step. Edit the HTML and push to `main`; GitHub Pages publishes in about a minute.

To add a project, copy one `<article class="card">` block in `index.html`.

Do not publish a home or mailing address on the site.

Photos live in `images/` (resized to 1000-2400 px wide). They are from Unsplash; keep the photographer credits in the About section's "Photography shoutout" when changing them.
